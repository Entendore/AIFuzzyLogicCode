1. OVERVIEW
================================================================================

This application is a sophisticated code generation system that creates Python
functions and CSS stylesheets WITHOUT using neural networks or deep learning.
Instead, it employs classical AI techniques including Genetic Programming (GP),
Monte Carlo Tree Search (MCTS), Fuzzy Logic, and Constraint Solving.

The system can:
- Generate Python functions from input/output examples
- Create CSS stylesheets from natural language-like specifications
- Optimize for multiple objectives simultaneously (correctness, simplicity, size)
- Refactor generated code for better quality
- Run in interactive mode for human-guided evolution

3. KEY ALGORITHMS EXPLAINED
================================================================================

3.1 GENETIC PROGRAMMING (GP)
---------------------------
Genetic Programming evolves computer programs using principles inspired by
biological evolution:

  1. INITIALIZATION: Create a population of random programs (ASTs)
  
  2. EVALUATION: Execute each program on test cases and calculate fitness
  
  3. SELECTION: Choose fitter programs to be parents (tournament selection)
  
  4. CROSSOVER: Combine parts of two parent programs to create offspring
     - Select random subtrees in each parent
     - Swap them to create new child programs
  
  5. MUTATION: Randomly modify programs
     - Point mutation: Change a single value (e.g., + to -)
     - Subtree mutation: Replace a subtree with a new random one
     - Hoist mutation: Replace a node with one of its children
  
  6. REPLACEMENT: Form new generation, keeping elite individuals

  This cycle repeats for many generations, with fitness improving over time.


3.2 MONTE CARLO TREE SEARCH (MCTS)
----------------------------------
MCTS guides program generation toward promising structures:

  The algorithm has four phases:
  
  1. SELECTION: Starting from root, select child nodes using UCB1 formula
     UCB1 = value + C × √(ln(parent_visits) / node_visits)
     - First term: exploitation (prefer high-reward nodes)
     - Second term: exploration (prefer less-visited nodes)
  
  2. EXPANSION: Add a new child node for an untried action
  
  3. SIMULATION: Complete the program randomly and evaluate fitness
  
  4. BACKPROPAGATION: Update statistics up the tree

  In this implementation, MCTS statistics guide grammar rule selection,
  biasing generation toward constructs that have historically led to
  fitter programs.


3.3 PARETO FRONT MULTI-OBJECTIVE OPTIMIZATION
----------------------------------------------
When optimizing multiple objectives (correctness, simplicity, size),
there's usually no single "best" solution. The Pareto front contains
all non-dominated solutions:

  Solution A dominates Solution B if:
  - A is at least as good as B in ALL objectives
  - A is strictly better than B in AT LEAST ONE objective

  Example:
                    Simplicity ↑
                          │
                     P1 ● │         ● P3
                          │
                          │    ● P2
                          │
                          │  ● P4 (dominated by P2)
                          └──────────────────→ Correctness

  Pareto Front = {P1, P2, P3}

  Crowding distance maintains diversity: solutions far from neighbors
  in objective space are preferred when trimming the front.


3.4 FUZZY LOGIC SYSTEM
----------------------
Fuzzy logic handles imprecise specifications like "make it moderately
complex and somewhat formal":

  1. FUZZIFICATION: Convert crisp values to membership degrees
     Example: complexity=7 → {simple: 0.0, moderate: 0.3, complex: 0.7}

  2. RULE EVALUATION: Apply if-then rules
     IF complexity is high AND formality is medium THEN style is modern
     
     Rule strength = min(membership_degrees) [using min t-norm]

  3. DEFUZZIFICATION: Convert fuzzy output to crisp value
     Centroid method: weighted average of output fuzzy set


3.5 CONSTRAINT SOLVING
----------------------
CSS generation uses constraint solving to find valid property values:

  Variables: border_radius, padding, color, etc.
  Domains: Possible values for each variable
  Constraints: Relationships (e.g., border_radius >= 8px)

  Algorithm: Backtracking with forward checking
  1. Choose an unassigned variable
  2. Try each value in its domain
  3. Check consistency with all constraints
  4. If consistent, recursively assign remaining variables
  5. If stuck, backtrack and try different value

  Forward checking prunes domains of future variables early,
  preventing obvious failures.

5. USAGE GUIDE
================================================================================

BASIC FUNCTION GENERATION:
--------------------------
```python
from code_generator_ai import CodeGeneratorAI, AIConfig

# Configure
config = AIConfig(
    population_size=100,
    generations=200,
    verbose_output=True
)

# Create AI
ai = CodeGeneratorAI(config)

# Define examples (input, expected_output)
examples = [
    (5, 10),    # double(5) = 10
    (3, 6),     # double(3) = 6
    (-2, -4),   # double(-2) = -4
]

# Generate
result = ai.generate_function(
    examples=examples,
    input_type='int',
    output_type='int'
)

# Get generated code
print(result.code_string)
